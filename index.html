A Modern Research Workflow with R and GitHub

A hands-on workshop for early-career researchers who use R

Author

Di Cook, Monash University

Link to the main GitHub repo: dicook/modern-research-workflow

This workshop is for early-career researchers, academics and students (honours, masters and PhD) who already use R for analysis and want their work to be easier to share, check and build on.

Before you arrive

To make the most of our time together, we ask you to set up your laptop before the workshop. Allow around 40 minutes for the setup, so you’ll be ready to follow along from the start.

Setup instructions

Who is this for?

You have written some R code but have used GitHub rarely or not at all

You are preparing your first papers, thesis or software and want good habits from the start

You are curious about using AI tools responsibly in research

You collaborate with others, or expect to, and want a smoother way to work together

You don’t need any experience with version control, package development or Quarto. You should be comfortable running R code and reading a data frame. Researchers from any discipline are welcome; the examples are chosen to make sense across fields.

Programme

0:00 – 0:15

Welcome and overview

0:15 – 0:55

Reproducibility and collaboration with GitHub

  • Structuring a research project: folders, naming, README, relative paths
  • Git basics: commit, push, pull, and recovering from mistakes using history
  • Pull requests and issues, and working with co-authors

Activity: make a project shared with a partner, make some changes, commit to it, merge commits, and open an issue describing next steps

0:55 – 1:00

Break

1:00 – 1:55

Publications and software

  • Writing with Quarto: papers and slides from one source
  • Citations, journal templates and linking results directly to code
  • Sharing research code: packaging basics, licences, Zenodo DOIs and citation files

Activity: render a short Quarto document with a figure and a citation

1:55 – 2:00

Break

2:00 – 2:30

AI in the research workflow

  • Useful applications: code help, debugging, documentation
  • Risks: hallucinated code and references, privacy, and disclosure norms

Activity: use an AI assistant to debug and document a function, then check the result

2:30 – 3:00

Data visualisation

  • Making figures reproducible and publication-ready

Activity: improve a poor chart, then script it so it regenerates from the data

3:00 – 3:15

Wrap-up

Presenter

Di Cook is Professor of Statistics at Monash University in Melbourne, Australia. Her research focuses on data visualisation, especially of high-dimensional data. She is an advocate of open source software and has practised reproducible research methods for almost two decades. Di is a Fellow of the American Statistical Association, a past editor of both the Journal of Computational and Graphical Statistics and The R Journal, an elected Ordinary Member of the R Foundation, and an elected member of the International Statistical Institute. She enjoys helping early-career researchers build habits that make their work easier to share, check and build on.
