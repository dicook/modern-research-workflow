AI in the research workflow

Where AI helps in R work

Code help

Explain unfamiliar code, suggest a first draft, translate between approaches

Debugging

Interpret an error message, spot a likely cause, propose a fix

Documentation

Draft comments, function docs and README sections from code you wrote

Treat it like a fast, confident colleague: one who is sometimes wrong, and who will likely bloat your code, use outdated styles and add too many checks. You stay responsible for the result.

Disclosure norms

  • AI tools generally cannot be listed as authors, and you remain accountable for everything submitted
  • Many journals and funders ask you to state what you used and for what
  • Check the policy of your journal, funder and institution before you submit
  • Record the tool, version and purpose as you work, so you can report it accurately

“Code debugging and function documentation were assisted by [tool, version]. All output was reviewed and tested by the authors.”

Debug a function

  • Fix this
  • Answer

Tip

  1. Run the broken function below and note what goes wrong
  2. Give an AI assistant a minimal example and the symptom. Do not paste any real data
  3. Apply its suggested fix, then check it yourself (see the next slide)
library(palmerpenguins)

group_means <- function(data, group, value) {
  tapply(data$value, data$group, mean)
}

group_means(penguins, "species", "flipper_length_mm")

A fix is not finished until you have tested it against something you trust.

group_means <- function(data, group, value) {
  tapply(data[[value]], data[[group]], mean, na.rm = TRUE)
}

group_means(penguins, "species", "flipper_length_mm")

# Compare with an independent calculation
aggregate(flipper_length_mm ~ species, data = penguins, FUN = mean)
  • The original bug is that data$value looks for a column literally called “value”. The second issue is that mean returns NA when the column has missing values. Discuss any differences between the assistant’s version and this one.
  • Did it handle missing values?
  • Does the documentation describe what the code actually does?
  • Did the assistant change anything you did not ask for?
  • Why didn’t it point out that there is a version of the penguin data in base R?

Data visualisation

A figure is an output, not a file

  • Data in, figure out, with no manual editing in between
  • Rerun the script and get the same figure
  • Changing the data or the style means changing one line, not redrawing

If you map variables to plot elements correctly with ggplot2, then the plot is a statistic.

Publication-ready habits

Show the data

Points or distributions, not only bars of means

One message per figure

The title or caption says what to notice

Label clearly

Axes with units, readable text size

Accessible colour

Colourblind-safe palettes, and not colour alone

Honest scales

Bars start at zero

Right size and format

Match the journal’s column width. Prefer vector formats (PDF, SVG) where allowed

Code 
library(forcats)

txhousing_price <- txhousing |> 
  group_by(city) |>
  summarise(price_m = median(median, na.rm=TRUE),
            price_q3 = quantile(median, 0.75, na.rm=TRUE),
            price_q1 = quantile(median, 0.25, na.rm=TRUE)) 

ggplot(txhousing_price, ) +
  geom_point(aes(x=fct_reorder(city, price_m), 
                 y=price_m)) +
  geom_errorbar(aes(x=fct_reorder(city, price_m), 
                    ymin=price_q1, 
                    ymax=price_q3), width=0) +
  scale_y_continuous("Median price ($ thousands)", 
                     breaks=c(100000, 150000, 200000), 
                     labels=c("100", "150", "200")) +
  xlab("") + 
  coord_flip()
  • Indication of variation added, using quartiles
  • City ordered by median price
  • Axes flipped to read city names
  • Repeated zeros removed, and labels tidied

Sizing of figures

```{r}
#| label: fig-flippers
#| fig-cap: "Flipper length by species."
#| fig-width: 3.5
#| fig-height: 2.5
#| out-width: 80%
#| fig-align: center
```
Option What it does
fig-width, fig-height Size the plot is drawn (inches)
out-width Scales the finished image on the page
fig-dpi Resolution of raster figures

If you find there is too much white space around the figure, adjust the width and height. The figure probably has the wrong aspect ratio for the space available.

The package patchwork is great for organising multiple plots into a figure.

Size your figure

In your shared-project, open paper.qmd

  1. Copy the code from the Fix tab of Spot the problems (plus the library() lines from Wrong) into a new chunk, with a label like fig-prices and a fig-cap
  2. Render. Then change fig-width and fig-height and render again. Which shape suits 46 city names?
  3. Try out-width: 50% and 100%. Notice the text gets smaller or larger with the image
  4. Refer to the figure in a sentence with @fig-prices
  5. Commit and push, with a message describing the change

Aim for labels that are readable, little white space, and a shape that fits the page. Try a tall, narrow figure first, e.g. fig-width: 5, fig-height: 8.

Captions and alt text

Captions should have three parts.

Part Answers Example
1. What What is this about? Exploring species differences in flipper length of penguins.
2. How What is shown, and how are variables mapped? Each point is one penguin, jittered to reduce overlap. Black points are species means.
3. So what What should the reader learn? Gentoo penguins have the longest flippers.

Alt text describes the plot for vision-impaired readers

Include Example
Chart type Scatter plot
What is plotted Flipper length ranging from 170 to 230 against Adelie, Chinstrap and Gentoo
The key pattern Adelie and Chinstrap range from 170 to 210, and Gentoo from 200 to 230

Caption your figure

  • To do
  • Answers

In paper.qmd, for your fig-prices chunk

  1. Write a three-part fig-cap: what it is about, how to read it, and so what
  2. Write fig-alt: chart type, what is plotted, and the key pattern
  3. Render, then right-click the figure and choose Inspect to check the alt text is there
  4. Swap with your partner: can they picture the plot from your alt text alone?
  5. Commit and push
```{r}
#| label: fig-prices
#| fig-cap: "What. How. So what."
#| fig-alt: "Chart type, what is plotted, the key pattern."
```

Hint: the data are monthly median house sale prices for 46 Texas cities, 2000 to 2015.

Example caption: “Median house prices across 46 Texas cities, 2000 to 2015. Each point is a city’s median monthly sale price, with lines spanning the first to third quartile; cities are ordered by median. Prices roughly double from the cheapest cities (Paris, Harlingen, around $80–90k) to the most expensive (Collin County, Midland, around $180–200k), and the more expensive cities also tend to vary more.”

Example alt text: “Dot plot with horizontal interval bars of median house price for 46 Texas cities, ordered from lowest to highest. Prices range from about $80,000 in Paris to about $196,000 in Collin County. Intervals are wider for the more expensive cities.”
