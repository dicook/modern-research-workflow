# A Modern Research Workflow with R and GitHub

A hands-on workshop by Di Cook (Monash University) for early-career researchers who use R and want their work to be easier to share, check and build on. It covers GitHub, Quarto, AI tools and data visualisation.

**Workshop website: <https://dicook.github.io/modern-research-workflow/>**

The website has the audience, programme, materials and presenter details. Before the workshop, please complete the [setup instructions](https://dicook.github.io/modern-research-workflow/setup.html) (about 40 minutes).

## Repository contents

| File | Purpose |
|------|---------|
| `index.qmd`, `index.scss` | Workshop home page and its styling |
| `setup.qmd` | Setup instructions for participants |
| `slides*.qmd` | Session slides |

Render with `quarto render <file>.qmd` and commit the resulting `.html` files and `*_files/` folders, which GitHub Pages serves directly.
