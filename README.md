## A Modern Research Workflow with R and GitHub

Website: [https://dicook.github.io/modern-research-workflow](https://dicook.github.io/modern-research-workflow/)

This workshop is for early-career researchers, academics and students (honours, masters and PhD) who already use R for analysis and want to make their work easier to share, check and build on. 

It suits people who:

* have written some R code but haven't used GitHub, or have used it only occasionally
* are preparing their first papers, theses or software and want good habits from the start
* are curious about using AI tools responsibly in research
* collaborate with others, or expect to, and want a smoother way to work together

No expertise in version control, package development or Quarto is needed. You should be comfortable running R code and reading a data frame. Researchers from any discipline are welcome, as the examples are chosen to be accessible across fields.

**Before you arrive please follow these [setup instructions](setup.html){target="_blank"}.** It will take about 40 minutes to complete, and then you will be fully ready to follow along with the workshop.

**Presenter**: Di Cook is Professor of Statistics at Monash University in Melbourne, Australia. Her research focuses on data visualisation, especially of high-dimensional data. She is an advocate of open source software and has practised reproducible research methods for almost two decades. Di is a Fellow of the American Statistical Association, a past editor of both the Journal of Computational and Graphical Statistics and the R Journal, an elected Ordinary Member of the R Foundation, and an elected member of the International Statistical Institute. She enjoys helping early-career researchers build habits that make their work easier to share, check and build on.

## Outline

- 0:00-0:15 Welcome and overview
- 0:15-0:55 Reproducibility and collaboration with GitHub
    - Structuring a research project: folders, naming, README, relative paths
    - Git basics: commit, push, pull, and recovering from mistakes using history
    - Pull requests and issues, and working with co-authors
    - *Activity*: make a project shared with a partner, make some changes, commit to it, merge commits, make an issue detailing some next steps
- 0:55-1:00 Break
- 1:00-1:55 Publications and software
    - Writing with Quarto: papers and slides from one source
    - Citations, journal templates and linking results directly to code
    - Sharing research code: packaging basics, licences, Zenodo DOIs and citation files
    - *Activity*: render a short Quarto document with a figure and a citation
- 1:55-2:00 Break
- 2:00-2:30 AI in the research workflow
    - Useful applications: code help, debugging, documentation
    - Risks: hallucinated code and references, privacy, and disclosure norms
    - *Activity*: use an AI assistant to debug and document a function, then check the result
- 2:30-3:00 Data visualisation
    - Making figures reproducible and publication-ready
    - *Activity*: improve a poor chart, then script it so it regenerates from the data
- 3:00-3:15 Wrap-up
